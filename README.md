# JOTA-JOTI 2026 – Code Checker

A simple and efficient web-based tool developed during **JOTA-JOTI 2026** to check, filter, and manage unique codes.

## About the Project

The Code Checker is designed to identify previously saved codes and display only the new, unsaved codes.

Users can add a list of codes to the system. Once a code is saved, the system remembers it. When the same code is submitted again, it automatically hides the previously saved codes and displays only the codes that have not been saved yet.

This makes managing large lists of codes faster, easier, and more organized.

## Key Features

- **Duplicate Detection:** Automatically identifies previously saved codes.
- **Saved Code Management:** Keeps track of all previously added codes.
- **Unsaved Code Filtering:** Displays only new and unsaved codes.
- **Automatic Code Hiding:** Hides codes that already exist in the saved database.
- **Bulk Code Checking:** Check multiple codes at once.
- **Unique Code Management:** Helps maintain a collection of unique codes.

## How It Works

1. Enter or paste a list of codes into the input field.
2. The system compares the submitted codes with previously saved codes.
3. Previously saved codes are automatically hidden.
4. Only new and unsaved codes are displayed.
5. Save the new codes to update the database.
6. Repeat the process whenever you receive another list of codes.

## Project Purpose

This project was developed to make code verification and duplicate management easier during JOTA-JOTI 2026.

It reduces manual checking, saves time, and helps prevent duplicate code entries.
